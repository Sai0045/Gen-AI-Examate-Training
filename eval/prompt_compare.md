## My conclusion
v2 is the better prompt. It gives the exact age, dose, route, site and latest age, while v1 often gives a very short answer (for example only "0.1 ml" for BCG). Both versions refuse the fever question, which is the safe behaviour. Q10 about pregnant women fails because the records say "pregnancy" and the question says "pregnant women", so TF-IDF finds no record, and Fractional IPV is missing from the 6-week answers for the same retrieval reason. The confidence value is not fully reliable, because the model gave "high" and "medium" for similar answers. The weak part is retrieval, not the prompt, so semantic search on Day 7 is the next improvement.
