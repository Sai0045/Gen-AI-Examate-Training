# TeekaTimer – Resume Highlights

- Developed TeekaTimer, an AI-powered vaccination assistant using Python, FastAPI, Streamlit, Groq LLM and Retrieval-Augmented Generation (RAG), retrieving information from official MoHFW documents with source citations.

- Built semantic document retrieval with ChromaDB and an agent workflow using LangGraph; implemented vaccine due-date tracking, dose records and feedback storage using SQLite.

- Added request validation, a bounded 5-minute response cache, and LLM latency/token logging; containerized and deployed the application using Docker and Render, with GitHub Actions CI, 19 passing automated tests and 885 indexed document chunks.
